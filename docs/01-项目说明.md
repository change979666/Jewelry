# Jewelry 项目说明

> 用途：对齐工作内容。本文件说明 Jewelry 是什么、当前做到哪、目录结构、环境变量、关键口径与后续计划。
> 最后更新：2026-09-27（V1.0 本地基础阶段）

---

## 1. 项目定位

Jewelry 是面向**沙特（KSA）与阿联酋（UAE）女性消费者**的日常轻奢饰品 DTC（B2C）独立站：

- 品类：耳饰、项链、手链、套装/礼盒；首发约 20–30 个 SKU。
- 语言：英文 + 阿拉伯文，**阿拉伯文原生 RTL**；英文为默认语言。
- 支付：**货到付款（COD）先行**，预留后续托管收银台；不接触银行卡号。
- 物流：先走人工履约流程。
- 价格带：以 SAR 为主，覆盖 SAR 99–399 战略区间（详见第 6 节）。

## 2. 本项目的来源（重要）

Jewelry 由旧内部项目 **Aromiso（香薰 B2B 站）**「**复制操作系统、重建生意**」而来：

- **保留**：通用平台能力——Astro + Cloudflare（Pages/D1/R2/KV）、后台壳层、RBAC 权限、i18n 机制、构建/测试门禁。
- **删除**：所有香薰/B2B 业务的页面、接口、内容、图片与历史数据。
- **重建**：Jewelry 自己的产品、订单、支付、物流、内容与品牌层（后续阶段）。

> 完整原始备份位于 `C:\Users\Administrator\Desktop\Aromiso`（含其 .git 历史），**勿动**，作为找回与对照的安全网。

## 4. 技术栈

| 层 | 选型 |
| --- | --- |
| 框架 | Astro 5（静态优先，`.astro` + TS） |
| 样式 | Tailwind CSS v4 |
| 托管 | Cloudflare Pages |
| 数据库 | Cloudflare D1（SQLite） |
| 对象存储 | Cloudflare R2（产品图） |
| 键值 | Cloudflare KV（草稿/自动保存） |
| 后端 | Cloudflare Pages Functions（`functions/`） |
| 测试 | Vitest |
| 工程化 | ESLint、Prettier、Husky + lint-staged |

## 5. 目录结构

```
Jewelry/
├── src/
│   ├── pages/
│   │   ├── [lang]/      # 公共门店页（en/ar）：首页、shop、about、faq、contact、cart 等
│   │   └── admin-v2/    # 后台页面
│   ├── components/      # 门店 + 后台组件
│   ├── layouts/         # BaseLayout（设置 lang 与 dir=RTL）
│   ├── content/         # 内容集合配置（blog、guides）
│   ├── data/            # 可编辑设置 settings.json
│   ├── lib/             # 前端/内容辅助
│   ├── i18n.ts          # 语言定义与翻译树
│   └── styles/          # 全局与后台样式
├── functions/           # Pages Functions：API 端点与 lib
├── migrations/          # Jewelry 的 D1 迁移（初始 schema 待写）
├── public/              # 静态资源（favicon、占位图、_redirects、robots）
├── scripts/             # 本地运维脚本
├── tests/               # Vitest 测试
└── docs/                # 项目文档、架构参考、变更记录
```

### 后台（admin-v2）当前保留模块

Dashboard（总览）、Commerce（Products 产品 / Orders 订单）、Customers（客户列表 / 订阅者）、Content（内容列表 / 编辑器）、Media（媒体）、Growth（SEO）、System（Settings / Users / Roles / Audit log）。

> **Collections、Promotions** 在旧项目中不存在，属于**待建**模块；侧边栏暂不链接，页面建好后再加入，不造假链接。

## 6. 商业口径（冻结，勿写死）

- 价格带（指示性）：Entry SAR 79–129 · Core SAR 149–249 · Statement SAR 299–399 · Set/Gift SAR 249–399。
- 四产品线：Everyday · Gulf Design · Gift · Statement。
- 金额：整数 minor units；货币 SAR、AED。
- 增值税：KSA 15%、UAE 5%，**走配置，不写死**。
- 支付：Provider-Agnostic；V1 仅 COD；预留 Hosted Checkout，不碰卡号。
- 物流：Manual 先行。
- 不做未经证实的宣称（hypoallergenic / waterproof / tarnish-proof / nickel-free / 18K solid gold 等），见 `functions/lib/fact-registry.json`。

## 7. 环境变量与密钥

- 品牌/导航/社媒：`src/consts.ts`、`src/data/settings.json`。
- Cloudflare 绑定：`wrangler.toml`（D1/R2/KV，当前为占位 ID）。
- 本地密钥：复制 `.dev.vars.example` 为 `.dev.vars`（已 gitignore）。

| 变量 | 用途 |
| --- | --- |
| `ADMIN_PASSWORD` | `/admin-v2` 登录密码 |
| `ADMIN_GITHUB_TOKEN` | 用于提交已发布内容的 GitHub PAT |
| `ADMIN_GITHUB_REPO` | `change979666/Jewelry` |
| `SILICONFLOW_API_KEY` | OpenAI 兼容 AI 服务密钥 |

安全要求：不提交 `.dev.vars`/`.env`/真实 token；**不要把 token 写进 git remote URL**。
