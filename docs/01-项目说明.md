# Jewelry 项目说明

> 用途：对齐工作内容。本文件说明 Jewelry 是什么、当前做到哪、目录结构、环境变量、关键口径与后续计划。
> 最后更新：2026-09-27（V1.0 → V1.1 P0 清障）

## 1. 项目定位

Jewelry 是面向**沙特（KSA）与阿联酋（UAE）女性消费者**的日常轻奢饰品 DTC（B2C）独立站：

- 品类：耳饰、项链、手链、套装/礼盒；首发约 20–30 个 SKU。
- 语言：英文 + 阿拉伯文，**阿拉伯文原生 RTL**；英文为默认语言。
- 支付：**货到付款（COD）先行**，预留后续托管收银台；不接触银行卡号。
- 物流：先走人工履约流程。
- 价格带：以 SAR 为主，覆盖 SAR 99–399 战略区间（详见第 6 节）。

## 2. 本项目的来源（重要）

Jewelry 由旧内部项目 **Aromiso（香薰 B2B 站）**「**复制操作系统、重建生意**」而来：

- **保留**：通用平台能力——Astro + Cloudflare（Pages/D1/R2/KV）、后台壳层、RBAC 权限、i18n 机制、构建/测试门禁。
- **删除**：所有香薰/B2B 业务的页面、接口、内容、图片与历史数据。
- **重建**：Jewelry 自己的产品、订单、支付、物流、内容与品牌层（后续阶段）。

> 完整原始备份位于 `C:\Users\Administrator\Desktop\Aromiso`（含其 .git 历史），**勿动**，作为找回与对照的安全网。

## 3.1 已完成（V1.0 Commerce Core，2026-09-27 冻结）

Commerce Core 不再是"待开发"——以下模块已实现并验证：

- **Schema 唯一事实源**：`migrations/0001–0010`，26 张表（products / product_variants /
  carts / cart_items / orders / order_items / order_addresses / order_events /
  payments / shipments / markets / collections / reviews / promotions /
  admin_users / admin_roles / admin_permissions / site_settings 等）。
  禁止重新引入旧项目的 `commerce_*` 表。
- **价格与结账**：价格只存在 `product_variants.price`（整数最小单位）；结账时服务端
  重新读取变体价格、按 `markets` 配置重算税费与运费（`src/lib/commerce/pricing.ts`），
  客户端提交金额一律不可信。
- **订单状态机**：`src/lib/commerce/order.service.ts` 的 `ORDER_TRANSITIONS` /
  `canTransition()`；Admin 改状态也必须走状态机，非法跳转返回 409。
- **库存一致性**：`src/lib/commerce/inventory.service.ts` —— 条件 UPDATE 原子预留 +
  失败补偿；`carts.checked_out_at` 抢占实现重复提交保护。
- **支付**：V1 仅 COD（`CODProvider`）；`HostedCheckoutProvider` 由
  `site_settings.feature.enable_online_payment` 开关控制，关闭时不渲染入口。
- **Admin V2**：RBAC 三表（owner/admin/editor/viewer）+ Cookie `jewelry_admin_v2`；
  首次登录时用 `ADMIN_PASSWORD` 引导创建 Owner。
- **i18n**：仅 en / ar；`src/i18n.ts` 为前后台共用的界面词典（en/ar 键集完全对称），
  页面级内容文案（FAQ、CTA、Footer 集合名）随组件内联，避免两套机制。
- **购物车 API**：`src/pages/api/cart/*`（Astro server endpoint，JSON API + `session_id` Cookie）。
- **API 与页面同源**：全部后端逻辑跑在 Astro server（`src/pages/api/**` + `src/middleware.ts`），
  由 Cloudflare 适配器编译为 `dist/_worker.js`；**已废弃的 `functions/` 目录已删除**，
  Pages 在有 `_worker.js` 时本就忽略整个 `functions/`。

**验证命令**：`npm run check`（0 error）、`npm test`（51 passed）、`npm run build`、
`migrations/0001–0010` 在全新库上按序回放（26 表）。

**当前目录数据**：`migrations/0008_jewelry_seed.sql` 是**演示 fixture**（8 个商品、
占位图、`country_of_origin` 为 NULL），上线前必须替换为真实 20–30 SKU。
真实数据的替换清单：验证成本、真实摄影、确认材质（镀金标注为"镀金"而非实金）、
原生阿拉伯语文案评审。

## 3.2 V1.1 P0 清障（2026-09-27）

在 V1.0 冻结基础上做了一轮「不推倒重来」的清障，解决三类会影响可售闭环的实质缺陷：

1. **阿拉伯语站全面失效（最严重）**。根因：`[lang]` 页在 `output: "server"` 下全部走 SSR，
   `getStaticPaths` 完全不生效、`Astro.props` 不注入，因此 `Astro.props.locale` 恒为
   `undefined`，回退 `"en"` —— `/ar/about`、`/ar/faq` 等 8 个页面实际渲染英文 `lang="en" dir="ltr"`。
   处置：新增 `src/lib/locale.ts#requireLocale()`，13 个 `[lang]` 页改为
   `requireLocale(Astro.params.lang)` 显式校验；`blog/[slug].astro` 重写为 SSR 形态
   （原读 `Astro.props.entry` 必然 500）。
2. **URL 前缀不一致 → 死链与软 404**。根因一：`getRelativeLocaleUrl()` 对默认语言不产前缀，
   导致 en 站内链全部指向 `/about/` 这类无前缀路径；根因二：`[lang]` 段无校验，任意单段路径
   （`/anything`）都以 200 + 首页内容渲染。处置：统一改用 `localizedUrl()`（`src/i18n.ts`，
   en 也带前缀 + 尾斜杠），覆盖 13 个文件、30 处调用；非法 locale 段返回 404。
   复核：`/xx/`、`/totally-random`、`/en/blog/any-slug`、`/en/collection/does-not-exist`
   全部 404，`/ar/*` 全部 `lang="ar" dir="rtl"`。
3. **Aromiso 残留清扫（第二批）**。RBAC 资源 `oem` → `shipping`（迁移
   `0010_jewelry_rbac_resource_shipping.sql`，本地实测 18 行改写成功），同步 Admin UI 文案与
   客户详情页 OEM tab 移除；`src/data/category-faqs.json` 由 1089 行蜡烛 FAQ 重写为
   9 个真实集合 × 3 条 × en/ar（27 条），事实口径对齐 FAQ 页；`SearchModal` 同义词表由
   蜡烛/西语/德语词表改为珠宝术语（并消除重复 key 静默覆盖）；`blog-related.ts` 类目映射改为
   珠宝类目；5 个 sitemap 修正域名、locale 列表与缺失路由。

**P0-7 可售闭环验证（API 级，本地 workerd）**：加购 → 结账（KSA，VAT 15%）→ 订单
`JW-T44HM5NB`（29800 + 1500 + 4470 = 35770 SAR）→ 库存原子扣减 25→23 → Admin 登录可见 →
状态机 `CONFIRMED → PROCESSING → SHIPPED → OUT_FOR_DELIVERY → DELIVERED` 全绿 →
非法流转返回 409 `ILLEGAL_TRANSITION`、同 session 重复提交被吸收（订单数仍 1）。
**尚未执行**：真实浏览器点击流（表单填单、后台按钮）与 20–30 SKU 真实数据替换。

> 域名只配置一处（`PUBLIC_SITE_URL` 构建变量，见 §7）。

## 6. 商业口径（冻结，勿写死）

- 价格带（指示性）：Entry SAR 79–129 · Core SAR 149–249 · Statement SAR 299–399 · Set/Gift SAR 249–399。
- 四产品线：Everyday · Gulf Design · Gift · Statement。
- 金额：整数 minor units；货币 SAR、AED。
- 增值税：KSA 15%、UAE 5%，**走配置，不写死**。
- 支付：Provider-Agnostic；V1 仅 COD；预留 Hosted Checkout，不碰卡号。
- 物流：Manual 先行。
- 不做未经证实的宣称（hypoallergenic / waterproof / tarnish-proof / nickel-free / 18K solid gold 等）。
  该红线已写入门店《条款》页面文案（`src/pages/[lang]/terms.astro`）并作为内容评审标准执行；
  旧机读副本 `functions/lib/fact-registry.json` 已随 `functions/` 目录一并退役，**当前无运行时闸门**，
  如需自动化拦截需在 Content Factory 侧重新落地（见 `docs/AGENT_OS_BLUEPRINT.md`，属历史设计）。
