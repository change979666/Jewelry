## 六、过程中的关键处置与纠偏

1. **fact-registry 重建**：truthfulness 引擎保留，但其香薰 `fact-registry.json` 一度被误删导致测试缺模块。处置：删除为香薰断言的 `truthfulness.test.ts`；重建干净空注册表 `functions/lib/fact-registry.json`（空认证/香精屋数组；unverifiableClaims 列 hypoallergenic、waterproof、tarnish-proof、nickel-free、18K solid gold 等 Jewelry 向红线）。
2. **admin-command-center.css 保留**：原判断可删，但核查发现 `AdminShell.astro`（所有后台页面使用）仍引用它，**故保留**，避免破坏构建。
3. **路径含 `[lang]`**：PowerShell 的 `Test-Path/Get-ChildItem` 会把 `[lang]` 当通配符，必须用 `-LiteralPath`；首次删除因此被静默跳过，已用 LiteralPath 重做。
4. **脚本编码**：PS 5.1 对无 BOM 的 `.ps1` 按 ANSI 读取，非 ASCII（—、ñ、阿拉伯文）会乱码；处置脚本保持纯 ASCII，阿拉伯文用 char code 拼装。
5. **占位图**：用 System.Drawing 生成浅灰 `public/images/placeholder-product.jpg`（1200×1500）与 `hero.jpg`（1600×900），避免图裂。
